# Contributing to TaskbarZ

TaskbarZ is an independent fork of [TaskbarX](https://github.com/ChrisAnd1998/TaskbarX). Please open an issue in this repository for bugs and proposed changes to the fork.

## Development

1. Open `TaskbarZ.sln` in Visual Studio 2022, or run `./build.ps1` in PowerShell.
2. Keep changes focused and describe how they affect Windows 10's classic taskbar.
3. Test opening and closing apps, changing tray icons, and restarting Explorer when relevant.
4. Run `./package.ps1` if the release contents change.
5. Submit a pull request with a short explanation and the test result.

Keep the original MIT license and attribution when redistributing modified source or binaries. Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
